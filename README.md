# 🚀 Featured Engineering & Research

## 🌀 PongVerse — Multi-View Human Motion Digital Twin

### `AthliX`

A **research-oriented multi-camera computer vision system** that reconstructs real human motion in 3D from synchronized camera views.

The system was developed and evaluated using a **table-tennis environment as a proof of concept**, while the underlying architecture is designed as a **domain-agnostic multi-view perception pipeline** rather than a sports-specific tracking system.

### Pipeline

```text
Multi-Camera Capture
        │
        ▼
Camera Calibration
        │
        ▼
YOLO Detection
        │
        ▼
DeepSORT Tracking
        │
        ▼
AlphaPose Estimation
        │
        ▼
DLT Triangulation
        │
        ▼
3D Reconstruction
        │
        ▼
Unity Digital Twin
```

**Engineering highlights**

* Built a **custom ~24K-image dataset**
* Developed a progressive multi-stage training pipeline
* Combined detection, tracking, pose estimation, geometry, and 3D visualization
* Fused observations from independent cameras into one reconstructed physical scene
* Designed the core geometry pipeline to transfer beyond the original table-tennis environment

**Core technologies**

`Python` · `OpenCV` · `YOLO` · `DeepSORT` · `AlphaPose` · `DLT` · `Multi-View Geometry` · `Unity 3D`

## 🖥️ AI Buddy — Context-Aware Visual Assistant

Currently exploring an AI assistant capable of understanding software interfaces and providing **real-time visual guidance directly on screen**.

Instead of only answering with text, the system is intended to understand what the user is seeing and provide grounded visual assistance through contextual overlays.

```text
Voice Command
      │
      ▼
Speech Understanding
      │
      ▼
Screen / UI Perception
      │
      ▼
Visual Reasoning
      │
      ▼
Grounded UI Element Detection
      │
      ▼
Interactive Overlay Guidance
```

**Research challenges**

`UI Grounding` · `Vision-Language Models` · `Coordinate Mapping` · `Hallucination Reduction` · `Real-Time Overlay Rendering`
